# Production deployment

Insplit consists of an Expo mobile app and an Express, Socket.IO, and MongoDB
API. The API needs a persistent WebSocket-capable service; do not deploy it as a
serverless function.

## API

The included `render.yaml` and `server/Dockerfile` are ready for a Render
Blueprint deployment and can also be used with other container hosts.

1. Push the repository to a Git provider and create a Render Blueprint from it.
2. Set `MONGODB_URI` and `CORS_ORIGINS`. JWT secrets are generated by the
   Blueprint. Configure one email provider as described below so verification
   and password-reset codes reach users. Set the three Cloudinary variables if
   receipt upload is used.
3. Allow the host's outbound network access in MongoDB Atlas and use a
   least-privileged database user.
4. Confirm `https://YOUR_API_HOST/health` returns `{ "status": "ok" }`.

| Variable | Required | Purpose |
| --- | --- | --- |
| `NODE_ENV=production` | Yes | Production logging and CORS behavior |
| `MONGODB_URI` | Yes | MongoDB connection string |
| `JWT_ACCESS_SECRET` | Yes | Access-token signing secret |
| `JWT_REFRESH_SECRET` | Yes | Refresh-token signing secret |
| `CORS_ORIGINS` | Yes | Comma-separated browser origins |
| `CLOUDINARY_*` | For uploads | Cloud name, API key, and API secret |
| `GMAIL_USER` + `GMAIL_APP_PASSWORD` | For email (option 1) | Gmail address and a 16-character Google App Password |
| `RESEND_API_KEY` + `EMAIL_FROM` | For email (option 2) | Resend API key and a sender on a verified domain |

### Email OTP delivery

Choose one provider; Gmail takes precedence if both are configured.

For Gmail, enable two-step verification on the sending Google account, create
an App Password, and set these values in `server/.env` locally or in the Render
service environment:

```dotenv
GMAIL_USER=your-account@gmail.com
GMAIL_APP_PASSWORD=your-16-character-app-password
```

Do not use the account's normal Gmail password. Restart/redeploy the API after
changing environment variables. A successful request logs
`[email sent via Gmail]`; when no provider is configured in development, the
server deliberately prints the OTP in the terminal instead.

Alternatively, use Resend:

```dotenv
RESEND_API_KEY=re_your_api_key
EMAIL_FROM=Insplit <no-reply@your-verified-domain.com>
```

Generate independent, high-entropy JWT secrets. Never commit `.env` files.

## Mobile release

Set `EXPO_PUBLIC_API_URL` to the HTTPS API origin without `/api` or a trailing
slash. The mobile client adds `/api`. Store the value in the EAS production
environment for automated builds.

```powershell
cd mobile
$env:EXPO_PUBLIC_API_URL="https://YOUR_API_HOST"
npm run typecheck
npx eas-cli build --platform android --profile production
```

Use `--platform ios` for iOS. A custom URL saved from the app profile takes
precedence over the build-time URL.

## Local verification

```powershell
cd server
npm run build
cd ../mobile
npm run typecheck
```
